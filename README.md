# Cook My Meal Website
This is a recipe sharing website that lets users add and delete recipes. 

## Tech Stack
Languages:
HTML
CSS
Javascript

## Author
Natalie Chebet

## Description
This website has three different pages. The home page enables navugation to the other two pages. The home page accesses the recipe list and their detsils through clickable links. One can add a recipe by using the button to access tha add recipe page. The recipes can be viewed and used.
